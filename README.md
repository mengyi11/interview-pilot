# InterviewPilot

基于目标岗位、官方技术资料与个人错题记忆的 AI 前端面试教练。

## 当前版本

第一阶段前端交互原型，包含：

- 模拟面试对话与追问
- 即时评分和回答建议
- 面试进度与能力表现
- 快捷提示和模拟回复
- 桌面端与移动端适配

当前回复使用本地模拟数据，不需要配置模型 API Key。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。
