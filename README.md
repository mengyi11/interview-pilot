# InterviewPilot

基于目标岗位、官方技术资料与个人错题记忆的 AI 前端面试教练。

## 当前版本

第一阶段前端交互原型，包含：

- 登录和游客体验入口
- 个人资料、简历选择、目标公司与职位设置
- JD 编辑与岗位匹配报告
- 个性化模拟面试对话与追问
- 即时评分、回答建议和能力表现
- 历史记录与错题本
- 桌面端与移动端适配

当前回复使用本地模拟数据，不需要配置模型 API Key。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。
